# Codex Usage Meter

Codex（OpenAI）の**週間使用量**と**5時間使用量**を、画面の端の小さな窓に常に表示するツールです。
Codex アプリを使っている間も、使い過ぎを先回りで避けられます。

![画面に置いたときのイメージ](docs/meter-on-screen.png)

画面に置いたときのイメージ（右下に出て、ドラッグで動かせます。背景の画面は作図です）

![タスクトレイのアイコン](docs/tray-card.png)

### これは何か

**パソコンで動く小さな常駐アプリ**です（Python で書いた1ファイル）。Codex の中に入れる拡張機能ではありません。

- パソコンにログインすると自動で起動し、Codex アプリを開いていなくても動きます。
- 使用量は、Codex アプリ（または CLI）と一緒に入っている `codex` に問い合わせて読みます。そのため Codex アプリか CLI が入っていて、ChatGPT の契約でサインイン済みであることが必要です。
- 入れるときだけ Codex に導入を手伝ってもらいます（手作業でも入れられます）。

### 表示される内容

- 週間（契約によっては5時間も）の使用%を、バーと色で表示します。色は 70%未満=緑／70%以上=黄／90%以上=赤。
- **経過**は、前回のリセットから次のリセットまでの期間が、いま何%進んだかです（5時間枠は5時間、週間枠は7日）。使用%が経過%より小さければ、時間の進みより使用が少ない状態（余裕あり）です。
- 出るのは Codex が返してきた枠だけです。契約によっては週間だけで、5時間枠が返ってこないことがあります。
- **リセット券**は、Codex の無料リセットの残り枚数と、いちばん早く切れる券の期限です（パソコンの時刻で表示）。
- **前回のリセット**（3行目）：週間の使用%が同じ週のまま10ポイント以上下がったとき、または次のリセット予定が予定の時刻より前に1日以上先へ跳んだときに「リセットがあった」と、パソコンの中の `resets.json` に記録して表示します。パソコンを止めていた間に起きた場合は、次に起動したときに記録します（時刻は目安）。マウスを乗せると、記録した履歴（直近5件）が出ます。
- 1分ごとに更新します。Codex で会話していなくても最新の値になり、確認で使用量が減ることはありません。
- **Codex使用量ページを開く**を押すと、Codex アプリの設定が開きます。左の「使用状況と請求」を押すと使用量が見られます（押した直後にメーターの上にも案内が出ます）。アプリの外から「使用状況と請求」へ直接飛ぶ方法が今の Codex アプリには無いため、1回押す手間が残ります。Codex アプリが入っていないパソコンでは、ウェブ版の使用量ページ（https://chatgpt.com/codex/settings/usage ）をブラウザで開きます。

### 起動・隠す・終了

| | Windows | Mac（未確認） |
|---|---|---|
| 自動で起動 | ログインすると起動（スタートアップに登録） | ログインすると起動（LaunchAgent に登録） |
| 手で起動 | スタートメニューで「Codex 使用量メーター」 | Launchpad か Spotlight で「Codex 使用量メーター」（~/Applications に作ります） |
| 隠す | 右クリック →「隠す」 | 右クリック →「隠す」 |
| 隠したのを出す | タスクトレイ（画面右下）の「C」のアイコンを押す | Dock のアイコンを押す |
| 終了 | 右クリック →「終了」、またはトレイのアイコンの右クリック →「終了」 | 右クリック →「終了」 |
| 右クリック | 右ボタン | 2本指クリック、または Control＋クリック |

- **単体の exe はありません。** 中身は Python のファイル1つで、Windows は `pythonw.exe`、Mac は `python3` が動かします。
- **2回起動しても1つだけ動きます。** すでに動いているときに起動すると、2つ目は立ち上がらず、動いている方（隠していればそれも）が表に出ます。
- **タスクトレイの「C」のアイコン**（Windows）は、週間の使用%に合わせて中の量と色（緑・黄・赤）が変わります。マウスを乗せると「Codex 週間 7%・リセットまで…」が出ます。
  - Windows 11 では、新しいアイコンは最初、タスクバーの「^」（隠れているインジケーター）の中に入ります。常に見えるようにするには、「^」を押して中のアイコンをタスクバーへドラッグするか、設定 → 個人用設定 → タスクバー →「その他のシステム トレイ アイコン」で「Codex 使用量メーター」をオンにします。
  - アイコン用の部品 `pystray` は install.py が入れます。入らなかったときは、アイコン無しで動きます（隠したメーターは、スタートメニューからもう一度起動すると出ます）。
- ドラッグで移動（位置は次回も保たれます）。右クリックで「今すぐ更新」「Codex使用量ページを開く」「常に手前に表示（オンのときチェック。ほかのウィンドウの下に隠れない）」「隠す」「作者について」「終了」。
- **版と最終データ取得の確かめ方**：右クリックのメニューの先頭に「Codex 使用量メーター v0.2.5」のように版が出て、その下に使用量の最終取得の時刻が出ます。下の行の左側の文字にマウスを乗せても版が出ます。不具合を報告するときは、この版を添えてください。

Claude Code 用の [claude-code-usage-meter](https://github.com/aikworks/claude-code-usage-meter) と同じ書式です。

## インストール（かんたん）

Codex アプリに、次の文を貼ってください。

> https://github.com/aikworks/codex-usage-meter の `codex_usage_meter.pyw` と `install.py` を、ホームフォルダの中の `codex-usage-meter` フォルダにダウンロードして。tkinter が使える Python 3 が入っていなければ入れて（Windows は python.org 版、Mac は python.org 版がおすすめ）、そのフォルダで `install.py` を実行して。終わったら、画面の右下に使用量の小窓が出たかを私に確かめるよう伝えて。

（Codex が許可を求めてきたら、内容を確認して許可してください。）

入れ終わると、画面の右下に小窓が出ます。次からはパソコンにログインすると自動で出ます。

## インストール（手作業）

1. このリポジトリをダウンロードし、好きな場所に置く（置いた場所から動かさない）。
2. そのフォルダで次を実行する。
   - Windows: `py install.py`（または `python install.py`）
   - Mac: `python3 install.py`

## 必要なもの・注意

- **Codex アプリまたは Codex CLI**（ChatGPT の契約でサインイン済み）。メーターはパソコンの中の Codex（`codex app-server`）に使用量を聞いて表示します。
- **Python 3（tkinter 付き）**。Homebrew の Python は tkinter が無いことがあります（`brew install python-tk`）。
- **動作確認の状況：** Windows（Codex アプリ）は作者が実画面で確認済みです。**Mac は未確認です**（動いた／動かないの報告を歓迎します）。
- Codex の場所が見つからないときは、環境変数 `CODEX_BIN` に codex の実行ファイルの場所を入れると使えます。
- このツールは**使用量を読んで表示するだけ**です。Codex の設定・会話・ファイルには触れません。ソースは `codex_usage_meter.pyw` の1ファイルです。
- 取得に失敗したときだけ、同じフォルダの `meter.log` に記録します。

## 外し方

1. 小窓を右クリック →「終了」。
2. 自動起動と手で起動する入口をやめる：そのフォルダで `install.py --uninstall` を実行（Windows はスタートアップとスタートメニューのショートカット、Mac は LaunchAgent とアプリケーションの登録を外します）。
3. フォルダごと消せば完全に外れます。
